🐍 Classic Snake Game in Python (Turtle Graphics)
🎮 Overview

This is a simple implementation of the classic Snake Game, built using Python’s built-in turtle module. It’s a fun and beginner-friendly project that demonstrates basic game logic, object movement, collision detection, and user input handling.

📽️ Demo

https://github.com/user-attachments/assets/3bf434be-1a56-46aa-b44e-fb18631699db

🧰 Tech Stack

Python 3.x

Turtle graphics module (comes pre-installed with Python)

🚀 Features

🐍 Snake movement using arrow keys

🍎 Random food generation

➕ Snake grows on eating food

🎯 Score tracking

💥 Collision detection (with walls & self)

🔄 Automatic reset on collision
📝 How to Run

Install Python if not already installed: https://www.python.org/downloads/

Clone or download this repo:

git clone https://github.com/your-username/snake-game-python.git
cd snake-game-python


Run the game:

python snake_game.py

📚 Learning Outcomes

Working with turtle graphics and animation

Event-driven programming using onkeypress()

Game loop logic and screen updates

Modular design and game state resets
